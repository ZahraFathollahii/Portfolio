## گانوتیک

- توسعه‌ی فروشگاه PWA فارسی با Next.js و پنل React برای سفارش‌ها، فیلتر محصولات و پرداخت.
- طراحی UI/UX و دیزاین سیستم قابل استفاده‌ی مجدد در فیگما.

**Tech Stack:** Next.js · React · TypeScript · Tailwind CSS · PWA · Figma

## MSSP

- طراحی UI/UX در فیگما و توسعه‌ی محیط‌های کاری مدیر، مشتری و SOC همراه با داشبوردهای امنیتی.
- اتصال کش، صفحه‌بندی و یکسان‌سازی پاسخ API؛ نوشتن تست سرویس‌ها و احراز هویت با Vitest.

**Tech Stack:** React · TypeScript · TanStack Query · Tailwind CSS · Recharts · Vitest · PWA · Figma

## پایش

- توسعه‌ی فرم‌های معاینات بالینی و ثبت‌نام چندمرحله‌ای با وضعیت مشترک Redux.
- اتصال گردش‌کارهای نقش‌محور سازمان و مرکز درمانی و کش داده‌های API برای پرونده‌ی سلامت شغلی.

**Tech Stack:** React · TypeScript · Redux Toolkit · TanStack Query · Tailwind CSS

## پیکوپت

- پیاده‌سازی زبان‌های فارسی و انگلیسی با چیدمان RTL/LTR و کش API با TanStack Query.
